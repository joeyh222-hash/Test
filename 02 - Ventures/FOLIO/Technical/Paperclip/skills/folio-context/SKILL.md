# FOLIO Context

FOLIO is a Taiwan-based AI-powered essay grading service built by a National Chengchi University (政大) English department team. We grade GSAT (大學學測) English compositions using the official 大考中心 四項 scoring standards and deliver personalized reports to cram schools within 3–5 business days.

**Core mission:** Let each student receive the precise feedback that previously only a few could access.

**Contact:** contact@foliopath.me
**Website:** https://foliopath.me
